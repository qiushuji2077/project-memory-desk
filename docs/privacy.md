# Privacy

Project Memory Desk is local-first by design.

## Principles

- User data stays local by default.
- Real project materials do not need to be uploaded to a third-party service.
- Public repositories should contain only code, docs, and anonymous demo data.
- Real workspaces should be ignored by Git.
- Data should be exportable, migratable, and easy to back up.

## Do not commit

- Real school or customer names
- Real interviews or meeting transcripts
- Real Word, PPT, PDF, audio, or screenshots
- Local absolute file paths
- API keys, tokens, cookies, or credentials

## Recommended ignored directories

- `private/`
- `workspace/`
- `uploads/`
- `recordings/`
- `exports/`
- `资料台数据/`
