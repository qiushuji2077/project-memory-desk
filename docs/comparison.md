# Comparison

This table compares product types objectively. Project Memory Desk is not a replacement for every tool; it focuses on project-state recovery through final memory and memory flow.

| 产品类型 | 数据是否本地优先 | 是否强调最终记忆 | 是否保留过程流 | 是否适合项目状态恢复 | 是否支持文件关联 | 是否面向交付型项目 | AI 自动化方向 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| Obsidian | 是 | 依赖用户组织 | 可通过链接、日记和插件实现 | 中等 | 强 | 通用笔记和知识库 | 插件生态与用户自配模型 |
| Notion | 否 | 依赖模板和维护习惯 | 可通过数据库实现 | 中等 | 强 | 通用协作和项目管理 | 云端 AI |
| Mem | 否 | 弱 | 弱 | 中等 | 中 | 个人知识捕捉 | 云端 AI |
| Tana | 否 | 依赖结构设计 | 强 | 中等 | 中 | 知识图谱和结构化笔记 | 结构化 AI |
| Linear | 否 | 面向任务和 issue 状态 | 保留 issue 轨迹 | 强 | 中 | 产品研发和工程协作 | 工作流自动化 |
| 普通文件夹 | 可本地 | 弱 | 弱 | 弱 | 强 | 依赖命名习惯 | 无 |
| Project Memory Desk | 是 | 强 | 强 | 强 | 计划增强 | 强 | 从提示词半自动到本地或自带 API |
